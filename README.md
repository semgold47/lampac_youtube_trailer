# YT Trailer for Lampa (SOCKS5)

Плагин добавляет в карточку фильма кнопку «YT трейлеры».  
При нажатии открывается список трейлеров с YouTube (через YouTube Data API v3).  
Выбранный трейлер проигрывается через ваш прокси-сервер (SOCKS5), чтобы не раскрывать реальный IP.

## Возможности
- Поиск до 10 трейлеров (720p максимум пока что) по названию и году
- Превью (миниатюры) трейлеров, проксируются через ваш сервер
- Воспроизведение видео через SOCKS5 (потоковое, без сохранения)
- Все настройки (API ключ, адрес сервера, SOCKS5 прокси) задаются в интерфейсе Lampa

## Требования
### Серверная часть (VPS / локальный компьютер)
- **Node.js** (рекомендуется версия 18 или выше)
- **npm** (обычно идёт вместе с Node.js)
- **yt-dlp** (скачивание видео с YouTube)
- Доступ к SOCKS5‑прокси (адрес, порт, логин/пароль если есть)

### Клиентская часть
- Приложение **Lampa** (актуальная версия)
- YouTube Data API v3 ключ (бесплатно в Google Cloud Console)

## Установка и запуск сервера
1. Установите Node.js и npm:
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs
   ```
2. Установите yt-dlp:
   ```bash
   sudo wget https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -O /usr/local/bin/yt-dlp
   sudo chmod a+rx /usr/local/bin/yt-dlp
   ```
3. Скачайте файл `server.js` из репозитория.
4. Перейдите в папку с сервером и установите зависимости:
   ```bash
   npm init -y
   npm install express socks-proxy-agent
   ```
5. **Сервер не требует указания SOCKS5 в коде** – адрес SOCKS5 вы будете вводить в настройках плагина Lampa.
6. Запустите сервер:
   ```bash
   node server.js
   ```
   По умолчанию он слушает порт 3000. Убедитесь, что порт открыт (например, `sudo ufw allow 3000`).

## Установка плагина в Lampa
1. Загрузите файл `youtube_trailer.js` на любой прямой хостинг (GitHub Pages, Pastebin с raw‑доступом, ваш собственный сервер).
2. В приложении Lampa откройте `Настройки → Расширения → Добавить плагин` и вставьте прямую ссылку на `youtube_trailer.js`.
3. После установки перейдите в `Настройки → YT трейлеры`.
4. Заполните три поля:
   - **YouTube API Key** – получите в Google Cloud Console (включите YouTube Data API v3, создайте API‑ключ без ограничений или с ограничением по IP/HTTP referrer).
   - **Прокси сервер** – полный URL вашего Node.js сервера, например `http://192.168.1.10:3000` или `http://ваш_vps:3000`.
   - **SOCKS5 прокси** – строка подключения к вашему SOCKS5‑прокси. Примеры:
     - `socks5://login:password@11.22.33.44:1080`
     - `socks5://127.0.0.1:9050` (локальный Tor)
5. Настройки сохраняются автоматически при выходе из меню.

## Использование
- Откройте любую карточку фильма или сериала.
- Под основными кнопками появится кнопка **«YT трейлеры»**.
- Нажмите её – откроется список найденных трейлеров с превью.
- Выберите нужный трейлер – начнётся воспроизведение через ваш SOCKS5‑прокси.

## Как это работает
1. Плагин получает название и год фильма.
2. Через YouTube Data API ищет трейлеры (до 10 штук).
3. Показывает список, используя прокси‑сервер для загрузки миниатюр (чтобы не светить IP клиента).
4. При выборе трейлера отправляет запрос на ваш Node.js сервер.
5. Сервер запускает `yt-dlp` с указанным SOCKS5‑прокси, скачивает видео в stdout и отдаёт его напрямую плееру. Никакие файлы не сохраняются.

## Важно о безопасности
- SOCKS5‑адрес (включая логин/пароль) передаётся в URL при каждом запросе к серверу. Если сервер открыт в интернете без шифрования (HTTPS), эти данные могут быть перехвачены. Рекомендуется использовать плагин **только в доверенной локальной сети** или настроить HTTPS на сервере.
- Сервер не ведёт логирование и не сохраняет видео/превью.
